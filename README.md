# Always Restock
GHPC quality-of-life mod that enables restocking without a conscious loader. When the loader is killed or unconsciousness, a penalty is added to the loading time, which by default is 3 seconds per shell to be moved. This value can be customized in the MelonLoader configuration file, but cannot be set below 0.

To install, simply place the DLL file in the /mods/ folder created by MelonLoader. The config entry will be generated after running the game once and closing.
